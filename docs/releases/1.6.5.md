# MKey 1.6.5

- Hiển thị tên ứng dụng đang giữ Secure Input trên thanh menu và trong thông báo cài đặt, giúp xác định cửa sổ đăng nhập hoặc ứng dụng cần đóng.
- Cập nhật tên khi ứng dụng giữ Secure Input thay đổi và xóa tên sau khi trạng thái này tắt.
- Hướng dẫn riêng khi Secure Input thuộc phiên đăng nhập macOS (`loginwindow`). Nếu macOS không cung cấp đủ thông tin, MKey giữ hướng dẫn chung.

MKey tiếp tục tự khôi phục bộ gõ khi Secure Input tắt và giữ nguyên việc bảo vệ nhập mật khẩu của macOS.

Hỗ trợ Apple Silicon và Intel, yêu cầu macOS 14 trở lên.
